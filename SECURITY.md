# Security Policy

## Supported Versions

Currently, only the latest release of the Zemail PHP SDK is supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |

## Reporting a Vulnerability

If you discover any security related issues, please email support@zemail.me instead of using the issue tracker.

We take security vulnerabilities seriously and will work to resolve them as quickly as possible. We will try to acknowledge your report within 48 hours, and will provide an estimated timeline for resolution.
